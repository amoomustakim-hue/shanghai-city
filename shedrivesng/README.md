# She Drives NG

Ride hailing in Nigeria with women drivers, built for women passengers first.

This folder holds all three products (it moves to its own `shedrivesng` repository once that exists):

| Folder | What it is | Status |
|---|---|---|
| `apps/web` | Public website: the service, driver registration, contact, app downloads | Concept next |
| `apps/mobile` | Rider and driver apps for Android and iOS | Not started |
| `apps/whatsapp-bot` | Booking and support over WhatsApp | Scope to be decided (not in the proposal) |
| `docs` | Proposal, product summary, brand guide, audit of the current site | Started |

Open this folder in your IDE and run Claude Code here; `CLAUDE.md` holds the working rules.
